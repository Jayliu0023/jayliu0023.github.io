A first look at gradient descent

How a loss function guides small updates to a model’s parameters.

This sample demonstrates the article format for this blog.

Define what to minimize

A loss function measures how a model’s predictions differ from the desired outputs. Training seeks parameter values that reduce this objective on the available training examples.

Follow the local slope

The gradient describes how the loss changes locally with each parameter. Gradient descent updates parameters in the opposite direction, scaled by a learning rate. A suitable step can reduce the loss; an excessively large step can overshoot or destabilize training.

Expect an imperfect path

Mini-batch gradients introduce sampling noise, and complex models can have non-convex objectives. A decreasing training loss is useful evidence of optimization progress, but it does not by itself establish good performance on unseen data.
